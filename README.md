# Portfolio Axel Frise

Portfolio d'Axel Frise, étudiant en BTS Communication (Compiègne) et alternant au service communication de la Ville de Creil.

Deux façons de le voir :
- **le site classique** (`index.html`) : accueil, projets détaillés avec fiches E5, projets développés, corpus, parcours, contact ;
- **le film « Hors champ »** : le même portfolio raconté au scroll (en cours de production).

## Lancer en local
Ouvrir `index.html` dans un navigateur, ou servir le dossier :
`python3 -m http.server` puis http://localhost:8000

## Arborescence
- `index.html` : le site (HTML, CSS et JS dans un seul fichier)
- `logo/` : logo vectorisé (PORTFOLIO et signature) en plusieurs couleurs
- `img/` : images du personnage et du film
